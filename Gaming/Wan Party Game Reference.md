# Wan Party Connect instructions

For all games:
* refer to the password we have always used for gaming in the past. If that isn't a clear enough hint, it should also be in our discord
* The server ip/url is also shared in our discord. For ports, refer to the [dedicated server git repo readme](https://gitlab.com/mredig/wan-party-dedicated-servers)

### Quake 3

1. check your bindings, screen/system settings, character name/avatar, etc
1. In the quake 3 main game menu, open the console (`~`) and run the following commands
	* `\password [password-no-brackets]`
	* `\connect [ourServer]:[serverPort]`
	
### Urban Terror 2.4/3.2

1. check your bindings, screen/system settings, character name/avatar, etc
1. In the quake 3 main game menu, go to mods
1. select the urban terror version
1. load
1. wait
1. now, in the UT game menu, open the console (`~`) and run the following commands
	* `\password [password-no-brackets]`
	* `\connect [ourServer]:[serverPort]`

### Counter-Strike 1.6

1. In the main game menu, `Find servers`
1. Choose the `Favorites` tab
1. Press the `Add a Server` button
1. enter `[ourServer]:[serverPort]`
1. it should appear in the list
1. when you press `Connect`, it should ask for the same password as others
